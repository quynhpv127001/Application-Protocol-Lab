⚡ Phase 5: gRPC & Protocol Buffers (High-Performance Microservices)

gRPC là chuẩn giao tiếp Microservices tốc độ cao sử dụng HTTP/2 đa kênh (Multiplexing) và nhị phân hóa qua Protocol Buffers (.proto). Module này triển khai đủ 4 mô hình Streaming, cơ chế kiểm soát Deadlines / Cancellation, và Trace Interceptor (Header x-trace-id).

🟢 gRPC Server Port: 9090
⚙️
The Backend Engineer Way: Kiểm soát tài nguyên bằng Context.current().isCancelled() khi Client vượt ngưỡng Deadline timeout; tự động gắn định danh x-trace-id xuyên suốt các lời gọi phân tán qua LogAndTraceServerInterceptor.
